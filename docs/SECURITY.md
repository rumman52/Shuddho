# Security and Privacy

- Do not log full user text.
- Use request IDs for traceability.
- Use `API_AUTH_TOKEN` or a real identity provider in production.
- Respect `allowProductImprovement` before retaining training/product analytics payloads.
- Add enterprise tenant policies before team rollout.
- Expand DLP preprocessing for secrets, PII, and regulated data.
- Enforce transport security, CSRF posture, and secure cookies in production.
