**Four parts:** A = architecture contracts, C = core reasoning/tools, P = personal context/experience, V = verification/release. Preserve CW numbers and separate adjacent transaction, automation and production-operations tracks.

**Selected next implementation after blocking CI:** C-03 Agent read credential isolation. This is security hardening only; it does not satisfy C-02 content capture. It changes only worker/browser receipt handling and tests, retaining human-supervised browser state. Acceptance: Agent worker context starts without replayed cookies, claims carry no storage state, successful Agent completions contain no retained cookie state, forged cookie receipts terminate irreversibly; human-supervised continuation remains unchanged. Feature stays default-off.
